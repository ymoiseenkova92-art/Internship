Подключённая AI-система

Смысловая и управленческая часть pipeline.

  • понимает задачу и материалы
  • строит storyline на 20 слайдов
  • выбирает типы слайдов
  • пишет и сокращает текст
  • выбирает изображения и стиль
  • возвращает JSON deck model
  • принимает правки и вызывает backend-функции
Точность и сборка

Python

  • извлекает текст из PDF и PPTX
  • проверяет JSON и DeckModel
  • считает layout, сетку и отступы
  • применяет style-library
  • собирает настоящий .pptx
  • делает preview, QA и версии
  • сохраняет и отдаёт финальный файл
