AI-конструктор

Neuform

Генератор, который превращает текстовый запрос в готовую HTML-страницу. Пользователь выбирает шаблон или начинает с промпта, уточняет результат через remix и получает код вместе с правилами дизайна.

PROMPT → HTMLREMIXDESIGN SYSTEMMOTION
ОТКРЫТЬ ПЛАТФОРМУ ↗

✣ Возможности

  • Генерация лендингов и UI
  • Публичная библиотека шаблонов
  • Remix и итерации по промпту
  • Дизайн-система вместе со страницей

Форматы

HTMLDESIGN.mdPreviewApp UISlides

⇩ DESIGN.md

Файл формируется как часть созданного проекта. Это не каталог, откуда любой готовый DESIGN.md можно свободно скачать.

Каталог можно изучать бесплатно. Для генерации, приватной работы и полноценного экспорта нужен trial либо платный план.

3.8/5

Кому подходит / вывод

Подходит, если нужно быстро создать новый лендинг и сразу получить HTML. Для поиска отдельного бесплатного DESIGN.md сервис менее удобен.

Каталог дизайн-систем

Getdesign

Каталог независимых разборов визуального языка известных сайтов. Пользователь выбирает брендовый референс и передаёт его описание AI-конструктору или кодинг-агенту.

550+ STYLESSITE ANALYSISLIGHT + DARKSTARTER KIT
ОТКРЫТЬ ПЛАТФОРМУ ↗

✣ Возможности

  • Поиск по каталогу референсов
  • Private DESIGN.md по URL
  • Светлая и тёмная темы
  • Starter kits с исходным кодом

Форматы

DESIGN.mdHTML previewLight / DarkSource code

⇩ DESIGN.md

Главное ограничение: без платного оформления скачать DESIGN.md не удалось.

Карточки и превью доступны для просмотра. В проверенном пользовательском сценарии переход к файлу потребовал платной подписки или покупки.

3.6/5

Кому подходит / вывод

Понятный сервис для выбора готового стилевого направления. Однако платный барьер не позволяет считать его источником свободно скачиваемых файлов.

Open-source среда

OpenDesign

Локальная open-source среда, а не только каталог. Агент извлекает стиль из сайта или создаёт систему по описанию, сохраняет её в проекте и применяет ко всем следующим материалам.

OPEN SOURCELOCAL FIRST140+ SYSTEMS21+ AGENTS
ОТКРЫТЬ ПЛАТФОРМУ ↗

✣ Возможности

  • Создание DESIGN.md по описанию
  • Извлечение стиля из сайта
  • Форк готовых дизайн-систем
  • Версионирование вместе с проектом

Форматы

DESIGN.mdHTMLPrototypeSlidesImageVideoAudio

⇩ DESIGN.md

Файл создаётся прямо в локальном проекте либо берётся из публичного GitHub-репозитория — без привязки к закрытому редактору.

Приложение, системы и шаблоны бесплатны по Apache-2.0. Расходы возможны только на подключённую внешнюю AI-модель.

4.7/5

Кому подходит / вывод

Подходит для постоянной работы над брендом: один переносимый DESIGN.md управляет сайтами, презентациями, изображениями и видео.

Библиотека стилей

Refero Styles

Большая визуальная база AI-readable дизайн-систем. В карточке стиля собраны цвета, типографика, интервалы, компоненты и правила — их можно передать агенту или перевести в код.

2K+ SYSTEMSTOKENSTAILWIND V4MCP
ОТКРЫТЬ ПЛАТФОРМУ ↗

✣ Возможности

  • Поиск и сортировка стилей
  • Визуальный просмотр токенов
  • Compact и Extended версии
  • Поиск агентом через Refero MCP

Форматы

DESIGN.mdTailwind v4CSS VariablesDesign Tokens

⇩ DESIGN.md

Полный текст показан на странице, но основное действие — Copy .md. Чтобы получить файл, его нужно сохранить вручную.

Базовые карточки стилей доступны без оплаты. Подключение полного поиска Refero к агенту относится к отдельной экосистеме.

4.2/5

Кому подходит / вывод

Подходит для поиска референсов и передачи токенов разработчику. Это самый богатый каталог, но не самый прямой путь к скачиваемому файлу.
